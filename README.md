# Group-Blue

Shared workspace for our Python study group: one place for the course material we follow and the assignment answers each member submits.

## Structure

- **`assignments/`** — assignment answers, one file per member (Michael, Reggie, Raifu, Stephen, Elnas). Assignment 1 was the personal-intro print exercise.
- **`python-master-course/`** — the shared curriculum: numbered modules from `01_hello_python` through functions, OOP, files, testing and the standard library, each with an `exercises.py`, plus `answers/` for the group's worked solutions.
- **`lesson1.py` / `assignment.py` / `python_assignment.py`** — starter and example files from our early sessions.

## Conventions

- Submit answers as `assignments/answerN_<name>.py` so everyone's work stays side by side and comparable.
- Course exercises live in `python-master-course/curriculum/<module>/exercises.py`; solve them locally and compare in session.
- Everything is standard-library Python 3 — run anything with `python3 <file>.py`.
